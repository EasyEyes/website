EasyEyes for Online Testing

Welcome! The open-source EasyEyes web app is meant to help anyone test vision online. EasyEyes measures screen size, and, with consent, uses the webcam of the participant's computer to track the participant's head and gaze positions. EasyEyes also enables use of any smartphone to emulate a wireless keypad, to allow testing at long viewing distances. We are using it with PsychoPy. You are welcome to use it with any online testing software.

How it works

From a table to an online study, in three steps.

  1. 01

    Write a spreadsheet

    Create your experiment table in any spreadsheet app, e.g., Excel. Each row is a parameter and each condition is a column.

    Manual ↗ Parameter Glossary ↗

  2. 02

    Compile it

    Sign in with your Pavlovia account and select your table. The Compiler checks it and turns it into a participant web app.

    Open the Compiler

  3. 03

    Run it

    Test yourself, and people you personally recruit, with just a Pavlovia account. To recruit participants online, add a service such as Prolific.
